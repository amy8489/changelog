# Changelog Component

A simple changelog component for a website, built with HTML and CSS only — no JavaScript. It shows a timeline of shipped work, newest first, with a vertical line, dots, and a link to the complete changelog.

## Files
- `index.html` — Changelog page with 7 entries
- `styles.css` — Layout, timeline positioning, and responsive styles

## How to run it
Double-click `index.html` to open it in your browser, or view the live site below.
